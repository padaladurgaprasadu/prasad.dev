01 — OVERVIEW

What is
NPU-1?

NPU-1 is a purpose-built Neural Processing Unit designed for the SynapLink Brain-Computer Interface system. Unlike general-purpose microcontrollers, NPU-1 is architected ground-up for real-time EEG signal classification — from raw electrode input to intent output in under 1ms.

The chip integrates a complete BCI signal chain: a 16-channel SPI input buffer, a 256-point FFT engine for spectral decomposition, a 31-feature extraction engine, and a 150-tree Random Forest inference engine — all in a 5×5mm die fabricated in 28nm CMOS.

Privacy is a first-class design constraint. Raw EEG data never leaves the chip. Only a 3-byte intent classification result is transmitted via BLE 5.2 with AES-128 encryption.

05 — PRIVACY & SECURITY

Security
Design.

Raw EEG — Never Transmitted
The Output Controller is hardware-locked to transmit only 3-byte classification packets. There is no software-accessible register to enable raw EEG streaming — this is a physical design constraint.
AES-128 Hardware Encryption
All BLE transmissions are encrypted at the hardware level using AES-128. Encryption keys are provisioned during manufacturing and cannot be read back via any external interface.
On-Chip Inference — No Cloud
All 150-tree Random Forest inference runs entirely within NPU-1. No data leaves the chip for processing. The BCI works fully offline — zero cloud dependency.
SPI Interface — Input Only
The SPI_MOSI / SPI_MISO / SPI_CLK pins are configured as write-only from the ADS1299 ADC. No external device can read SRAM contents via SPI.
3-Byte Output Protocol
Output format: [Intent Class (1 byte)] [Confidence (1 byte)] [Checksum (1 byte)]. This minimal packet carries no biometric information beyond the classified intent.
PRIVACY BY DESIGN

NPU-1 processes ~50,000 raw EEG samples per second internally — but transmits only ~10 intent packets per second. A 5,000× compression ratio ensures your brain data stays on-chip.
