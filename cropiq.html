01 — OVERVIEW

What is
CropIQ?

CropIQ is an AI-powered crop recommendation system that leverages multispectral satellite imagery from the Sentinel-2 constellation to identify optimal crops for a given region. Unlike traditional soil-sampling methods, CropIQ processes remote sensing data — making recommendations accessible without physical fieldwork.

The system uses a fine-tuned EfficientNet-B4 convolutional neural network trained on spectral band combinations (RGB + NIR + SWIR) to classify land into 10 major crop categories with 94.3% validation accuracy.

An Android mobile application allows farmers to select their location, fetch satellite imagery automatically, and receive crop recommendations with confidence scores in real-time.

PROBLEM STATEMENT

Indian farmers lose 15–20% of potential yield annually due to unsuitable crop selection. Soil testing is expensive and inaccessible in rural areas. CropIQ provides a zero-cost, satellite-driven alternative that any farmer with a smartphone can use.

02 — ARCHITECTURE

System
Pipeline.

End-to-end flow from satellite to crop recommendation

STEP 01
Satellite Capture
Sentinel-2 L2A multispectral imagery fetched via Copernicus Open Access Hub. 13 spectral bands at 10m–60m resolution.
STEP 02
Preprocessing
Band selection (B2, B3, B4, B8, B11, B12), atmospheric correction, NDVI computation, patch extraction (64×64px), normalization.
STEP 03
EfficientNet-B4
Fine-tuned EfficientNet-B4 with modified input layer (6 channels). ImageNet pretrained weights, custom classification head for 10 crop classes.
STEP 04
Classification
Softmax output over 10 crop classes. Confidence score, top-3 recommendations, regional suitability scoring with seasonal context.
STEP 05
Android App
Kotlin app fetches GPS coordinates, calls FastAPI backend, displays recommendations with confidence bars, crop calendar, and soil tips.

Key Findings
BEST RESULT
EfficientNet-B4 outperformed all baselines with 94.3% accuracy using only 19M parameters — 7× fewer than VGG-16.
NIR BANDS
Including NIR & SWIR bands improved accuracy by 6.2% over RGB-only baseline — key for distinguishing crop types with similar visual appearance.
CONFUSION
Highest confusion between Sorghum ↔ Millet (spectral similarity). NDVI temporal features identified as solution for future work.
MOBILE
TFLite quantized model achieved ~120ms inference on mid-range Android device — suitable for real-world rural deployment.
